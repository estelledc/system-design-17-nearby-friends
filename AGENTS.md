# Repository instructions

- This is an independent clean-room learning repository for one bounded nearby-friends invariant.
- Keep social authorization, location freshness, spatial inclusion, server delivery, device receipt, and real-world proximity as
  separate facts.
- Never add real credentials, people, social graphs, device identifiers, precise locations, routes, or copied third-party prose,
  diagrams, images, data, or code.
- Preserve unrelated work. Stage exact paths, keep commits single-purpose, and do not add co-author trailers unless requested.
- Infrastructure-dependent conclusions require the matching real service in public CI; mocks cannot prove cross-service behavior.
- A benchmark is a bounded synthetic observation for its exact fixture and runtime, never a production-capacity or safety claim.
